# Referências técnicas

Consultadas até 13/09/2026. Estas referências orientam a integração; não representam validação de credenciais ou publicação nas contas do usuário.

- [Electron: introdução e distribuição](https://www.electronjs.org/docs/latest): runtime desktop por plataforma.
- [Electron: segurança](https://www.electronjs.org/docs/latest/tutorial/security): isolamento, sandbox e navegação restrita.
- [Electron: safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage): proteção da lembrança local da senha pelo armazenamento seguro do sistema operacional.
- [OpenRouter: chat completions](https://openrouter.ai/docs/api/api-reference/chat/send-chat-completion-request): chamadas de geração.
- [OpenRouter: catálogo de modelos](https://openrouter.ai/docs/api/api-reference/models/get-models): IDs e metadados dinâmicos.
- [OpenRouter: tokens de raciocínio](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens): configuração de esforço e reserva de tokens para a resposta final.
- [OpenRouter: saídas estruturadas](https://openrouter.ai/docs/guides/features/structured-outputs): validação de JSON por schema e roteamento para provedores compatíveis.
- [NCBI: E-utilities](https://www.ncbi.nlm.nih.gov/books/NBK25501/): pesquisa e recuperação de registros PubMed.
- [OpenRouter: web search server tool](https://openrouter.ai/docs/guides/features/server-tools/web-search): ferramenta `openrouter:web_search`, Exa, limites e citações retornadas pelo serviço. A API está em beta.
- [Tiptap: Markdown](https://tiptap.dev/docs/editor/markdown): integração do editor visual com Markdown e extensões de conteúdo.
- [WordPress: autenticação](https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/): Application Passwords.
- [WordPress: posts](https://developer.wordpress.org/rest-api/reference/posts/): criação e atualização.
- [Meta: coleção oficial Instagram](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api): APIs, contêineres e publicação.
- [Cloudflare R2: ciclo de vida](https://developers.cloudflare.com/r2/buckets/object-lifecycles/): expiração automática das imagens temporárias.
- [Pi](https://github.com/earendil-works/pi): toolkit avaliado, ainda não integrado. O repositório antigo `badlogic/pi-mono` redireciona para este endereço.
